// 04 — ABOUT

ADHD-powered builder. My brain fires fast, and I aim it at software. One month after opening this GitHub account I had 27 public repositories live — AI-native terminals, policy routers for LLMs, Telegram gate bots, media players and red-team dashboards.

I don't wait for permission to learn. I fork Bitcoin Core to read how consensus code is written, clone NumPy to study numerical kernels, and dissect a Rust Spark replacement to understand distributed compute. Then I build my own versions — smaller, weirder, mine.

Everything I ship is open source, dependency-light where it matters, and built for the joy of making ideas real.
